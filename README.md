# ワイン テイスティング練習（wine-tasting-trainer）

ワインエキスパート2次試験（テイスティング）対策の個人用PWAです。
iPhoneのSafariで開き「共有 → ホーム画面に追加」するとアプリとして使えます。

## 機能

- 📝 **テイスティングコメント選択練習** — 本番の解答用紙を模した用語選択シートで回答し、模範解答と照合・採点
- 🃏 **主要品種フラッシュカード** — 白10種・赤11種の特徴（外観・香り・味わい・決め手・主産地）を暗記
- ❓ **品種当てクイズ** — 模範解答から生成したコメントを読んで品種を4択で推測
- 📊 **過去の出題品種 傾向データ** — 2011〜2025年の出題実績ランキングと年度別一覧

## データの編集

すべてのデータは `data.js` に集約されています。

| 定数 | 内容 |
|---|---|
| `VOCAB` | 用語選択シートの項目・用語・選択数（白/赤別） |
| `WINES` | 練習用ワインと模範解答（コメント練習・クイズ共通） |
| `GRAPES` | フラッシュカードの品種データ |
| `PAST_EXAMS` | 過去の出題実績（出典: [ワイン受験.com](https://www.wine-jyuken.com/second_exam/kakonosyutudai)） |

用語・選択数はJ.S.A.解答用紙の近似です。最新の本番シートに合わせて編集してください。

## 更新の配布

ファイルを変更して公開先へpushした後、`sw.js` の `CACHE_VERSION` を上げると、
各端末では次回起動時に新しいバージョンへ更新されます。

## ローカルでの動作確認

```bash
python -m http.server 8737
```

を実行し、ブラウザで http://localhost:8737 を開きます。
